# A12 Studio

Репозиторий содержит два независимых раздела:
- Лендинг (`index.html`, `en/index.html`, `assets/`): статичный сайт для GitHub Pages.
- Контент-кухня (`content/`): методички, промты и сценарии для соцсетей студии и клиентов.

## Работа с контентом

Когда просят идеи, сценарии, тексты или редактуру:

1. Сначала прочитай `content/04-brief.md` (контекст студии, аудитория, голос) и опирайся на него. Если в брифе пусто там, где это важно для задачи, задай 1–2 точных вопроса или явно назови гипотезу.
2. Следуй методу из `content/01-anatomy-of-text.md` (слои сверху вниз: задача → смысл → аргумент → структура → ритм → слово) и `content/02-short-video-scripts.md` (крючок, удержание, финал, чек-лист).
3. Сценарии пиши по шаблону из `02-short-video-scripts.md` (таблица кадров) и сохраняй в `content/scripts/ГГГГ-ММ-краткое-название.md`.
4. Кадры описывай так, чтобы их можно было сгенерировать ИИ: персонаж, действие, ракурс, свет, стиль, 9:16.
5. Идеи давай с запасом (обычно 15–30), каждая — одной строкой: смысл + первый кадр. Отмечай лучшие и объясняй выбор.
6. Будь редактором, а не поддакивающим: говори прямо, где вода, где банальность, где зритель пролистнёт.
7. Пиши по-русски, живым языком, без канцелярита и пустых усилителей («уникальный», «качественный», «эффективный»).
