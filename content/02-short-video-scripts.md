# Сценарии коротких роликов (Reels / Shorts / TikTok / VK Клипы)

Короткий ролик — это текст, у которого есть **картинка, звук, время и кнопка «пролистать»**. Всё из [анатомии текста](01-anatomy-of-text.md) работает, но с поправкой: зритель уходит не через абзац, а через **1,5 секунды**.

---

## Как зритель принимает решение остаться

```
0.0–1.5 с   «Это мне?»          → визуальный крючок (стоп-кадр в ленте)
1.5–3 с     «Что будет дальше?» → словесный/смысловой крючок, открыта петля
3–10 с      «Стоит ждать?»      → обещание + первая награда
10 с–финал  «Не зря ли я тут?»  → награды каждые 3–5 секунд, нарастание
Финал       «Что мне с этим?»   → вывод / поворот / действие
После       «Пересмотреть? Сохранить? Отправить?» → повод для репоста
```

Алгоритмы смотрят на: **досмотры, пересмотры, сохранения, репосты, комментарии**. Под каждый метрик — свой приём (см. ниже).

---

## Крючок: первые 3 секунды

Крючок работает **тремя каналами одновременно**: картинка + текст на экране + первая фраза. Они должны дополнять, а не дублировать друг друга.

### Визуальные крючки (особенно сильны в ИИ-видео)
- **Невозможное:** то, что нельзя снять камерой (кот раздаёт карты, город из еды). Это главное преимущество ИИ — используй его в первом кадре, а не в середине.
- **Движение в кадр:** что-то влетает, падает, разбивается.
- **Крупный план на непонятном:** зритель хочет понять, что это.
- **Середина действия:** начинай не с начала истории, а с самого острого момента.
- **Взгляд в камеру + пауза.**
- **Контраст / нарушение нормы:** офисный костюм под водой.

### Словесные крючки (формулы)
| Тип | Формула | Пример |
|---|---|---|
| Разрыв ожидания | «Все думают X. Это не так.» | «ИИ-видео — это не дёшево. Дёшево — это ошибаться.» |
| Цена ошибки | «Вы теряете X, потому что Y» | «Ваша реклама выгорает за неделю. Вот почему.» |
| Секрет / закулисье | «Как на самом деле...» | «Как на самом деле делается ролик за 30 секунд.» |
| Прямое обращение к сегменту | «Если вы [кто], [что]» | «Если вы эксперт и ненавидите сниматься — смотрите.» |
| Конкретный результат | цифра + срок | «3 ролика, 1 день, ни одной съёмки.» |
| Незавершённое | обрыв фразы | «Мы сгенерировали 400 кадров, чтобы оставить один. И вот почему...» |
| Вопрос-проверка | вопрос, на который хочется ответить | «Угадаете, где реальное видео, а где ИИ?» |
| Конфликт | «X против Y» | «Съёмка против генерации: одинаковый бюджет.» |

**Анти-крючки (убивают ролик):** «Привет, сегодня я расскажу...», логотип в первой секунде, медленная заставка, «Друзья, ...».

## Удержание: середина ролика

- **Награда каждые 3–5 секунд:** новый факт, смена кадра, поворот, шутка, визуальный сюрприз.
- **Открывай новую петлю до закрытия старой** («...но это не главное»).
- **Паттерн-интеррапт:** смена плана, звука, ракурса, темпа каждые 2–4 секунды.
- **Нарастание ставок:** каждое следующее — сильнее предыдущего.
- **Нет «воды»:** вырежи всё, без чего смысл не меняется. Короткий ролик длиной 25 с почти всегда лучше 40 с.

## Финал

Варианты:
- **Поворот (twist):** переворачивает смысл всего ролика → провоцирует пересмотр.
- **Петля (loop):** последний кадр/фраза перетекает в первый → бесшовный повтор, растут досмотры.
- **Вывод одной фразой:** то, что хочется переслать.
- **Открытый вопрос:** → комментарии.
- **CTA, согласованный с задачей:** одно действие, не три.

| Хочешь | CTA / приём |
|---|---|
| Сохранения | Полезная структура, чек-лист, «сохраните, чтобы не потерять» |
| Репосты | Узнаваемость «это про нас», вывод-цитата, «отправьте тому, кто...» |
| Комментарии | Спорный тезис, выбор «A или B?», недосказанность |
| Подписку | Серийность: «часть 1», персонаж, к которому хочется вернуться |
| Заявку | Конкретный следующий шаг + снятое возражение |

## Форматы коротких роликов

1. **Мини-история с персонажем** (основа ИИ-сериалов): герой → желание → препятствие → поворот. 15–45 с.
2. **Объяснялка через метафору:** сложное через визуальный образ («ваша воронка — это дырявое ведро» — и показываем ведро).
3. **До / После:** контраст, а между ними — «мост» (продукт).
4. **Миф vs правда.**
5. **Закулисье / процесс:** как это делается. Отлично работает для студии.
6. **Список:** «3 ошибки...» — самая сильная последней.
7. **POV (точка зрения):** «POV: вы заказали ролик и...»
8. **Реакция / разбор:** разбираем чужой креатив/тренд.
9. **Эксперимент / челлендж:** «Сделали рекламу за 1 час. Что получилось.»
10. **Диалог двух персонажей:** конфликт позиций = естественная драматургия.
11. **Тренд + смысл:** трендовый звук/формат, но с собственным смыслом.
12. **Серия:** «Эпизод 3» — эффект сериала, возвращает аудиторию.

## Шаблон сценария

Пиши сценарий **таблицей**: это сразу и текст, и раскадровка, и ТЗ на генерацию.

```markdown
# [Рабочее название]

**Площадка / формат:** Reels 9:16, 25–30 с
**Задача (А → Б):** зритель не знает, что ... → понимает, что ...
**Аудитория и ступень осознанности:**
**Смысл одной фразой:**
**Целевое действие / метрика:** сохранение / репост / комментарий / заявка
**Формат:** мини-история / до-после / ...
**Тон:**

| # | Время | Кадр (что видим) | Текст на экране | Голос / реплика | Звук | Задача блока |
|---|---|---|---|---|---|---|
| 1 | 0–2 с | | | | | Крючок |
| 2 | 2–6 с | | | | | Открыть петлю |
| 3 | ... | | | | | Награда 1 |
| ... | | | | | | |
| N | | | | | | Финал / CTA |

**Подпись к посту:** (первая строка — второй крючок)
**Обложка:** (текст 3–5 слов)
**Варианты крючка для A/B:** 1) ... 2) ... 3) ...
**Промты для генерации ключевых кадров:** (по кадрам)
```

Готовый пример — [`scripts/`](scripts/).

## Особенности сценария для ИИ-видео

- **Каждый кадр = отдельная генерация.** Пиши кадры так, чтобы их можно было сгенерировать: кто, где, что делает, ракурс, свет, стиль.
- **Короткие планы (2–4 с)** — ИИ-анимация стабильнее на коротких отрезках, и это совпадает с темпом соцсетей.
- **Консистентность персонажа:** заранее опиши персонажа (внешность, одежда, палитра) и копируй описание в каждый промт.
- **Сюжет держится на действии и мимике, а не на сложной физике** (руки, текст в кадре, мелкие объекты — зоны риска).
- **Используй невозможное** — иначе зачем ИИ? Но невозможное должно служить смыслу, а не быть фокусом ради фокуса.
- **Звук делает 50% ролика:** сразу закладывай в сценарий звуковые акценты.

## Чек-лист сценария перед производством

- [ ] Смысл формулируется одной фразой, он спорный и наш
- [ ] Понятно, на какой ступени зритель и куда его ведём
- [ ] Первый кадр останавливает ленту без звука
- [ ] Первая фраза открывает петлю за ≤ 3 с
- [ ] Нет приветствий, логотипов и разгона в начале
- [ ] Награда / смена каждые 3–5 с
- [ ] Ролик понятен без звука (субтитры / текст на экране)
- [ ] Финал: поворот, петля или вывод — не «спасибо за внимание»
- [ ] Один CTA, совпадает с целевой метрикой
- [ ] Вырезано всё, без чего смысл не меняется
- [ ] Прочитано вслух с таймером
- [ ] Есть 3 варианта крючка для теста
