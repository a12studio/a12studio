# Библиотека промтов для идей

Промты для работы со мной (Claude) или любой другой нейросетью. Каждый решает свою задачу. Подставь данные в `[скобках]`.

**Главное правило:** чем больше контекста в начале, тем точнее идеи. Перед любым промтом вставь **контекст-блок** (или заполни его один раз в [`04-brief.md`](04-brief.md), и в этом репозитории я подтяну его сам).

```
КОНТЕКСТ
Бренд/эксперт: [кто]
Продукт: [что продаём, цена, формат]
Аудитория: [кто, возраст, роль, ситуация]
Их боли: [3–5 пунктов]
Их желания: [3–5 пунктов]
Возражения: [почему не покупают]
Чем мы отличаемся: [1–3 пункта]
Тон: [как говорим]
Площадка: [Reels / TikTok / Shorts / VK]
Задача контента: [охват / доверие / заявки]
```

## А. Исследование аудитории (сырьё для идей)

### A1. Карта болей по слоям
```
На основе контекста составь карту болей аудитории в 4 слоях:
1) функциональные (что не получается сделать),
2) эмоциональные (что чувствуют),
3) социальные (как выглядят в глазах других),
4) скрытые (в чём не признаются даже себе).
По 5 пунктов на слой. Каждую боль сформулируй ЯЗЫКОМ КЛИЕНТА — как он сказал бы это подруге/коллеге, а не маркетолог.
```

### A2. Внутренний монолог
```
Напиши внутренний монолог [типичного представителя аудитории] в момент, когда он [ситуация, связанная с проблемой]. 150–200 слов, от первого лица, живым языком, с сомнениями и самооправданиями. Потом выдели из монолога 10 фраз, которые можно использовать как крючки для роликов.
```

### A3. Возражения и их корни
```
Перечисли 15 возражений, из-за которых аудитория не покупает [продукт]. Для каждого: что человек говорит вслух → что на самом деле стоит за этим → какой ролик мог бы снять это возражение (формат + смысл одной фразой).
```

### A4. Ступени осознанности
```
Распиши 5 ступеней осознанности (не знает о проблеме → знает о проблеме → знает о решениях → знает о нас → готов купить) для нашей аудитории. Для каждой ступени: что человек думает, что ему нужно услышать, и 3 идеи коротких роликов.
```

## Б. Генерация идей

### Б1. Матрица «боль × формат»
```
Возьми 5 главных болей аудитории и 6 форматов коротких роликов: мини-история с персонажем, до/после, миф vs правда, POV, закулисье, метафора-объяснялка. Сделай таблицу 5×6, в каждой ячейке — идея ролика одной строкой (смысл + что видим в первом кадре). Отметь звёздочкой 5 самых сильных и объясни почему.
```

### Б2. Разрыв ожидания
```
Перечисли 15 распространённых убеждений аудитории о [тема/ниша], которые на самом деле неверны или неполны. Для каждого: «Все думают...» → «На самом деле...» → доказательство/механизм → крючок для ролика на 1 строку.
```

### Б3. Невозможное как метафора (для ИИ-видео)
```
Придумай 12 визуальных метафор для [абстрактная проблема/ценность продукта], которые невозможно или очень дорого снять камерой, но можно сгенерировать ИИ. Для каждой: образ → какой смысл он передаёт → сюжет на 15–20 секунд в 3–4 кадрах. Метафоры должны быть понятны без слов.
```

### Б4. Персонаж и сериал
```
Предложи 3 концепции персонажа для серии коротких роликов бренда [бренд]. Для каждого: кто он, чего хочет, его слабость/смешная черта, его отношение к продукту, визуальный образ (для генерации), мир вокруг. Затем для лучшей концепции — 10 идей эпизодов, каждый закрывает одну боль или возражение.
```

### Б5. Конфликт
```
Найди 10 конфликтов в мире нашей аудитории: между ожиданием и реальностью, между двумя подходами, между людьми (клиент/подрядчик, начальник/сотрудник), внутри человека. Для каждого — сюжет ролика-диалога двух персонажей на 20–30 секунд с поворотом в конце.
```

### Б6. Перенос из другой отрасли
```
Возьми 5 приёмов/форматов, которые отлично работают в [чужая ниша: кулинария, фитнес, true crime, ASMR, обзоры техники, детские мультики], и перенеси их на нашу тему. Для каждого: исходный приём → наша версия → пример ролика.
```

### Б7. Инфоповоды и тренды
```
Предложи 10 идей роликов, привязанных к [событие/сезон/тренд/дата]. Только те, где тренд естественно связан с нашим смыслом, а не притянут. Для каждой: тренд → наш смысл → крючок → почему это не будет выглядеть как «прилипли к хайпу».
```

### Б8. Закулисье
```
Перечисли 15 моментов из нашей работы [описание процесса], которые клиенты не видят, но которые показывают нашу экспертизу, ценность или просто интересны. Для каждого — идея ролика-закулисья и вывод, который должен сделать зритель (не говоря его прямо).
```

### Б9. Кейс → 5 роликов
```
Вот кейс: [описание: задача, что сделали, результат]. Разложи его на 5 разных коротких роликов с разных углов: 1) проблема клиента, 2) неочевидное решение, 3) процесс/закулисье, 4) результат в цифрах, 5) урок, применимый зрителем. Для каждого — крючок и смысл.
```

## В. Работа с готовой идеей

### В1. Проверка идеи
```
Оцени идею ролика по 7 критериям (1–5 баллов): сила крючка, ясность смысла, спорность/новизна, связь с продуктом, потенциал репоста, реализуемость в ИИ, соответствие тону. Затем предложи 3 способа усилить самый слабый критерий.
```

### В2. 10 крючков
```
Для ролика со смыслом «[смысл]» напиши 10 крючков (первая фраза + что в первом кадре), используя разные механики: разрыв ожидания, цена ошибки, вопрос, конкретная цифра, незавершённая фраза, обращение к сегменту, конфликт, секрет, невозможная картинка, POV. Отметь 3 лучших для A/B-теста.
```

### В3. Сценарий из идеи
```
Напиши сценарий короткого ролика [длительность] по шаблону из 02-short-video-scripts.md. Смысл: [...]. Формат: [...]. Целевое действие: [...]. Кадры описывай так, чтобы их можно было сгенерировать ИИ. После сценария — 3 альтернативных финала (поворот, петля, вопрос).
```

### В4. Адвокат дьявола
```
Ты — скептичный зритель из нашей аудитории, которому надоела реклама. Посмотри на этот сценарий и честно скажи: на какой секунде ты пролистнёшь и почему, какая фраза звучит как реклама/вода, во что ты не поверишь. Потом — как редактор: что исправить.
```

### В5. Одна идея — много форматов
```
Возьми идею [идея] и сделай из неё: 3 коротких ролика под разные сегменты аудитории, 1 карусель, 1 пост, 1 сторис-серию (5 экранов). Сохрани единый смысл, меняй угол и крючок.
```

## Г. Контент-план

### Г1. Рубрикатор
```
Предложи 5–6 рубрик для соцсетей [бренда] с соотношением задач: охват / доверие / продажи. Для каждой: название, задача, формат, частота, 5 идей роликов. Рубрики должны быть узнаваемыми сериями, а не просто темами.
```

### Г2. План на месяц
```
Составь контент-план коротких роликов на 4 недели, [N] роликов в неделю. Чередуй рубрики и ступени осознанности. Таблица: дата, рубрика, ступень, смысл одной фразой, крючок, формат, целевое действие.
```

## Как работать со мной продуктивнее

- **Проси много, выбирай мало.** Пусть будет 30 идей, а оставишь 3. Количество — путь к качеству.
- **Давай обратную связь конкретно:** «эта идея ближе, потому что...». Я подстрою следующую партию.
- **Сталкивай идеи:** «соедини идею 4 и идею 11».
- **Проси «более странно» / «более просто» / «более по-человечески»** — это рабочие ручки регулировки.
- **Не принимай первую версию сценария.** Запускай В4 (адвокат дьявола) и проси 2–3 итерации.
