## Как со мной работать

Открой сессию Claude Code в этом репозитории и пиши обычным языком:

- «Дай 20 идей роликов про возражение „ИИ выглядит дёшево“»
- «Напиши сценарий на 25 секунд по идее 7, формат мини-история»
- «Разнеси этот сценарий как скептичный зритель»
- «Отредактируй текст поста по слоям»
- «Сделай контент-план на октябрь»

Правила работы описаны в [`CLAUDE.md`](../CLAUDE.md): я прочитаю бриф и методички сам.

## Цикл одного ролика

```
Исследование (A1–A4) → 30 идей (Б*) → отбор 3 (В1) → 10 крючков (В2)
→ сценарий (В3) → адвокат дьявола (В4) → правка → производство
→ данные → следующая версия
```
